# Flappy Bird Reinvented

**Created by Henry Green, a gifted and talented student doing a passion project:)**

A modern, feature-packed take on the classic arcade game built with HTML5 Canvas, CSS, and JavaScript. Includes custom loading screens, player accounts, cloud-saved progress, upgrades, and a global leaderboard. 

## Driving Question to Create this Game
What can be done to make an old 80s arcade game interesting to kids again?

## Play Online

* **Live Game:** [Flappy Bird Reinvented](https://flappy-reinvented.surge.sh)
* **Developer Portfolio:** [Xelotics Games](https://xelotics.surge.sh)

## Planned Features

* **Reinvented Gameplay:** Classic tap-to-flap arcade action upgraded with new mechanics, power-ups, and obstacles.
* **Player Accounts:** Sign up and log in to track your personal stats across devices.
* **Cloud Saves & Unlocks:** Automatically save earned coins, high scores, and unlocked skins/upgrades.
* **Global Leaderboard:** Compete against other players for a spot in the Top 10.

## Project Structure

| File | Description |
| :--- | :--- |
| `index.html` | Main game page, loading screen, main menu, and pop-up modals |
| `style.css` | Custom styling, animations, and responsive layout |
| `game.js` | Core game loop, physics, collision detection, and new mechanics |
| `auth.js` | User authentication (Sign Up, Log In, Log Out) |
| `database.js` | Cloud database connection for saving progress and fetching leaderboard scores |

## Tech Stack

* **Frontend:** HTML5 Canvas, CSS3, Vanilla JavaScript
* **Hosting:** Surge.sh
* **Backend / Database:** Firebase or Supabase *(for accounts & leaderboards)*
