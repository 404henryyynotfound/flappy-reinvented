# Security Policy

## Supported Versions

Security updates and bug fixes are actively maintained for the latest live version of **Flappy Bird Reinvented** on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main` (Latest) | :white_check_mark: |
| Older commits   | :x:                |

## Reporting a Vulnerability or Exploit

We take the security of player accounts, cloud saves, and the Top 10 global leaderboard seriously. 

If you discover a security vulnerability, Supabase database issue, score-tampering exploit, or bug that compromises fair play, **please do not report it in a public GitHub issue**.

Instead, report it privately by emailing **greenhenry441@gmail.com** with:

* **Description of the issue** (what happened and where, e.g., `auth.js`, `database.js`, or leaderboard submission)
* **Steps to reproduce** the vulnerability or exploit
* **Potential impact** (such as unauthorized account access, score manipulation, or exposed credentials)
* **Screenshots or proof-of-concept details**, if helpful

## What to Expect

* **Acknowledgment**: You will receive a confirmation reply within **48–72 hours** letting you know your report is being reviewed.
* **Investigation & Fix**: Valid vulnerabilities and leaderboard exploits will be investigated and patched as quickly as possible.
* **Responsible Disclosure**: Please keep details of the vulnerability private until a fix has been deployed to protect players and game integrity.

Thank you for helping keep **Flappy Bird Reinvented** safe and fair for everyone!
